# SCSORA

脚本：[download_scsora.py](../download_scsora.py)。下载上游逐日再分析的年度 NetCDF 原件，不做区域或变量裁剪。

## 配置与用法

- 年份必填，脚本支持 2001–2024。
- 每年一个 `SCSORA_daily_YYYY.nc`，默认保存到当前工作目录。
- 只使用公开下载入口；依赖安装和代理设置见 [README](../README.md)。

```powershell
# 查询大小和本地状态，不下载数据正文
python download_scsora.py 2001 -n -o "D:\SCSORA"

# 下载一个年份
python download_scsora.py 2001 -o "D:\SCSORA"

# 连续或不连续年份
python download_scsora.py 2001,2003-2005 -o "D:\SCSORA" --stop-on-error
```

| 参数 | 作用 |
| --- | --- |
| `-n/--dry-run` | 发送 HEAD 查询远端大小，显示计划；查询失败时需检查日志，不能只看退出码 |
| `--overwrite` | 重新下载已存在的最终文件 |
| `--stop-on-error` | 一个年份失败后停止；默认继续其他年份 |

## 空间、校验与恢复

年度原件体积很大，按约 172 GiB/年做初步空间规划，实际大小以 HEAD 结果为准。多年度下载需容纳全部已完成年份；重下已有文件时还需容纳新文件。临时文件与最终文件在同一目录，改名不额外复制一份。

脚本按年串行，没有 `-j` 参数。下载先写 `.part`，中断后重跑相同命令进行字节续传；不要删除需要继续使用的 `.part`。最终文件按远端字节数检查，不做校验和或 NetCDF 内容校验。跨运行续传未保存旧文件的远端版本标识，若已知上游替换过原件，应将旧临时文件移开后重新下载。

正式下载退出码：`0` 全部成功或跳过，`1` 有年份失败，`2` 参数错误，`130` 中断。
