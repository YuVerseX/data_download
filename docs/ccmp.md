# RSS CCMP V3.1 海表风场

测试样本已按用户要求删除；下文样本路径和体积仅保留为历史验证记录，不代表文件仍在磁盘上。

`download_ccmp.py` 下载 RSS CCMP V3.1 L4 十米东西向/南北向风及观测支持量。默认区域为 **105–125°E、0–25°N**；新增下载器 `--bbox` 顺序统一为 **W E S N**。这里只支持递增的0–360°经度区间，不处理跨零点区域。

- [RSS V3.1实际目录](https://data.remss.com/ccmp/v03.1/)
- [2025年12月实际文件目录](https://data.remss.com/ccmp/v03.1/Y2025/M12/)
- [2026年7月实际文件目录](https://data.remss.com/ccmp/v03.1/Y2026/M07/)
- [NASA PO.DAAC产品DOI](https://doi.org/10.5067/CCMP-6HW10M-L4V31)

2026-09-12核查：稳定产品选V3.1，不沿用论文中的V2。服务目录最早日期为1993-01-02，1993年1月仅列出29个日文件，因此不能假设从首日起绝对连续。最新目录日为2026-07-20；**2025年全部365个日期已经逐月核对，是本次最新完整年**。未完整扫描1993–2024所有日期；脚本每次下载前会验证请求日期全部存在，不补造缺失日。`latest` 根据执行当天的系统日期和服务端全部日文件集合确定完整年，不硬编码2025。

RSS静态说明仍写覆盖到2023年7月，且示例文件名与实际目录不同；这里以实际目录和NetCDF元数据为准：`CCMP_Wind_Analysis_YYYYMMDD_V03.1_L4.nc`。RSS说明更新批次可能暂缺最后一天，后续更新才补齐，因此不能只检查12月31日就称全年完整。

## 变量、网格与时间语义

| 输出 | 实际变量 | 单位与含义 |
|---|---|---|
| 原始四时次区域文件 | `uwnd`, `vwnd` | `m s-1`，海面上10m东向、北向风 |
| 原始四时次区域文件 | `nobs` | 卫星观测支持数；无量纲，有效范围0–100；0不是缺测或坏文件 |
| 可选本地日均 | `uwnd`, `vwnd` | 原单位；当日00/06/12/18 UTC四个分析时刻等权均值 |
| 可选本地日均 | `nobs_sum` | 四个时次nobs之和，**不是去重后的独立日观测数** |
| 可选本地日均 | `valid_sample_count` | 两个风分量都有效的时次数0–4 |

实际文件为0.25°网格，全球坐标720×1440，纬度中心-89.875..89.875，经度0.125..359.875。源文件部分`actual_range`与坐标不一致；脚本校验真实坐标，裁剪后重写坐标范围及全局空间范围。必要科学属性、来源、许可和历史处理说明保留。

默认边界按格点中心包含原则裁剪，输出经度 **105.125–124.875°E（80列）**、纬度 **0.125–24.875°N（100行）**；边界105/125/0/25不是本产品的格点中心，不会插值补造边界。自定义边界若没有任何格点，在请求目录或下载数据前拒绝。

源产品每天一个文件，包含00、06、12、18 UTC四个分析场；这是6小时间隔的分析时刻，不能宣称每一帧是6小时平均或独立卫星观测。CCMP通过变分分析融合卫星和调整过的ERA5背景；虽然使用ERA5背景，下载的仍是CCMP，不能作为与ERA5完全独立的验证资料。

`--daily-mean`另存日均，原四时次文件始终保留。采用`skipna=False`，任何风分量某时次缺测使该分量当日均值缺测；缺失/重复/跨UTC日时次直接拒绝，不插值、不用少于四帧平均。时间戳设UTC12时，`time_bounds`为当日00时到次日00时。日均只是四个分析场的离散算术平均，不能称为独立的连续24小时观测平均。

RSS提示陆地区域风值也可能出现，但不保证陆地风正确；本下载器保留上游缺测，不把所有非缺测格点自动视为海洋有效区。后续应使用研究海域掩膜。

## 下载、恢复与认证

使用RSS HTTPS全球日文件，匿名读取本次成功；RSS页面写有注册后下载要求，正式使用应遵守其注册、许可和引用要求。若返回401/403，脚本明确停止并提示按RSS官方说明处理，不猜测认证头或打印凭据。本实现未支持带认证的RSS接口，若未来目录权限改变，需要按官方提供的方式补充，不能声称已验证。

没有在RSS找到可核实的官方服务端裁剪接口，因此先下载全球一天到`raw/*.nc.part`，核对Content-Length、版本、变量、单位、精确时间、网格覆盖、nobs范围和全变量可读性，再提交原始文件；裁剪后同样写临时文件并重开校验，最后原子替换正式文件。默认成功后删除全球中间文件；`--keep-global`保留它。

不支持字节断点续传，失败重跑当前`.part`从头开始；已校验的源文件可复用，完整区域文件则跳过，无需重复下载。已有最终文件损坏或请求参数/来源不一致时停止，避免覆盖用户文件；请检查后移走损坏文件或使用新的输出目录。同一输出目录不要并发运行多个实例。

如果原始区域四时次文件完整、仅缺日均文件，直接读取区域文件生成日均，不再下载全球原件。日均复用校验包括UTC边界、`nobs_sum`的0–400整数范围、有效样本数的0–4整数范围以及风场缺测与样本数的一致性。

仅依赖项目已有的`numpy`、`xarray`、`netCDF4`，网络使用Python标准库。`--retries 3`是总尝试次数。执行中显示日进度，遇到缺文件在开始数据下载前终止。`dry-run`会读取月目录（长时段可有数百次小请求）及一次HEAD，不下载NetCDF。

## 命令

```powershell
# 单日计划，仅目录和HEAD
python download_ccmp.py --start-date 2025-12-31 --end-date 2025-12-31 --bbox 115 116 15 16 --daily-mean -n

# 正式计划：2001年至执行当天服务端最新完整年
python download_ccmp.py 2001-latest --bbox 105 125 0 25 --daily-mean -n

# 正式下载（请自行执行，并替换输出路径占位符）
python download_ccmp.py 2001-latest --bbox 105 125 0 25 --daily-mean -o "<正式数据根目录>\CCMP"
```

也支持`2001,2003-2005`；日期闭区间不能与年份同时使用。去掉`--daily-mean`仅保存原始四时次区域产品。
