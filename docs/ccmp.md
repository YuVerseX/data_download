# RSS CCMP V3.1 海表风场

脚本：[download_ccmp.py](../download_ccmp.py)。下载全球日文件后裁剪区域，保留每天四个分析时次，可额外生成 UTC 日均。

## 默认配置

- 日期：省略时使用 `2001-latest`，最新完整年由源站目录核实；也支持显式年份和起止日期。
- 区域：南海 `105 125 0 25`，顺序为 **西、东、南、北**；经度为递增的 0–360° 区间，不跨零点。
- 网格：0.25°；默认区域经度 105.125–124.875（80 点）、纬度 0.125–24.875（100 点）。
- 变量：`uwnd vwnd nobs`，固定下载。
- 输出目录：默认 `ccmp`；四时次文件 `ccmp_v3.1_YYYYMMDD_6hourly.nc`，可选日均文件 `ccmp_v3.1_YYYYMMDD_daily.nc`。

无需在脚本中配置账号，按 [README](../README.md) 安装依赖。需要 `numpy`、`xarray`、`tqdm`，正式下载还需要 `netCDF4`。

## 用法

```powershell
# 目录与一个文件的 HEAD 检查，不下载数据正文
python download_ccmp.py --start-date 2001-01-01 --end-date 2001-01-01 -n -o "F:\CCMP"

# 下载一天，另存日均
python download_ccmp.py --start-date 2001-01-01 --end-date 2001-01-01 --daily-mean -o "F:\CCMP"

# 指定年份
python download_ccmp.py 2001,2003-2005 --daily-mean -o "F:\CCMP"

# 西北太平洋：先查看计划，再移除 -n 下载
python download_ccmp.py 2001-latest --bbox 100 180 0 60 --daily-mean -n -o "F:\CCMP_NorthwestPacific"
```

日期首尾均包含，年份与日期参数互斥；显式日期不能早于 1993 年或包含今天及未来日期。缺少请求日期时在数据下载前停止，不补造日期。`latest` 逐月检查候选年份，不假定整个年份完整。

| 参数 | 作用 |
| --- | --- |
| `--daily-mean` | 另存 UTC 四时次均值，保留原四时次文件 |
| `--keep-global` | 保留校验后的全球原件，默认输出成功后删除 |
| `--timeout` | 连接/套接字读取超时秒数，默认 90，不是整文件总时限 |
| `--retries` | 总尝试次数，默认 3；重试临时网络错误和部分 HTTP 错误 |
| `--proxy direct` | 禁用显式代理；VPN/TUN 仍可能转发流量 |
| `--proxy http://127.0.0.1:10808` | 为本次运行指定代理，端口按本机配置修改 |
| `--progress-interval` | 字节进度条最短刷新间隔秒数，默认 0.5 |

## 下载量、校验与恢复

`-n` 查询目录并对一个全球日文件发送 HEAD，用其大小粗略估算流量；不下载 NetCDF、不创建输出目录。比较代理与直连的完整传输速度需另做小范围实际测试。

**区域裁剪不减少全球原件的下载量。** 单日原件通常为数十 MiB；输出目录需容纳最终文件和一天的临时处理空间，脚本提示至少预留 100 MiB 临时磁盘。`--keep-global` 还需容纳全部全球原件。实际耗时受网络、服务端、校验和写盘影响。

按日串行，没有 `-j`。先写 `raw/*.nc.part`，检查响应长度、版本、变量、单位、时间、网格和数据可读性后提交全球原件；区域文件同样先写临时文件并重新打开校验。

重跑会校验并跳过完成文件；已有全球原件可复用，仅缺日均时可从区域四时次文件生成。不支持字节续传，未完成日从头下载。损坏或请求不匹配的正式文件保留并报错，没有 `--overwrite`；同一输出目录不要并发运行多个实例。

## 数据含义与来源

| 变量或输出 | 含义 |
| --- | --- |
| `uwnd`、`vwnd` | 10 m 东向、北向风，单位 `m s-1`；00/06/12/18 UTC 分析场 |
| `nobs` | 卫星观测支持数；0 不代表文件损坏 |
| 日均 `uwnd`、`vwnd` | 四分析时刻等权平均；某分量任一时次缺测则该分量日均缺测 |
| 日均 `nobs_sum` | 四时次支持数之和，不是去重后的独立观测数 |
| 日均 `valid_sample_count` | 两个风分量均有效的时次数，0–4 |

日均时间戳为 UTC 12 时，边界为当天 00 时至次日 00 时。它是四个分析场的离散均值，不是连续 24 小时观测平均；原四时次也不是六小时平均。缺失、重复或跨日时次会报错。

CCMP 融合卫星与 ERA5 背景，不能作为与 ERA5 完全独立的验证资料。区域裁剪不生成海域掩膜，使用时仍需检查缺测、质量和陆地范围。
