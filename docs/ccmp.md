# RSS CCMP V3.1 海表风场

交互终端显示月份检查、逐日完成和当前文件字节进度条（速度、预计剩余时间）；重定向日志时自动关闭动态条。完成数包含校验后跳过的已有文件。

`download_ccmp.py` 下载全球日文件、校验后裁剪区域，可另外生成UTC日均。默认区域为105–125°E、0–25°N；`--bbox` 顺序为 **W E S N**，经度使用递增的0–360°区间，不支持跨零点。

## 安装与运行

在运行下载器的同一个Python环境安装依赖：

```powershell
python -m pip install numpy xarray netCDF4 tqdm

# 先完成一天的下载、裁剪和日均，确认网络及本地写入均正常
python download_ccmp.py --start-date 2001-01-01 --end-date 2001-01-01 --bbox 105 125 0 25 --daily-mean -o "F:\CCMP"

# 全时段下载，最新完整年份在运行时核查
python download_ccmp.py 2001-latest --bbox 105 125 0 25 --daily-mean -o "F:\CCMP"

# 只核对目录及一个文件的HEAD，不下载数据
python download_ccmp.py 2001-latest --daily-mean --dry-run
```

支持`2001,2003-2005`；日期闭区间不能与年份同时使用。缺少请求日期时在数据下载前停止，不补造日期。`latest`会逐月检查候选年份全部日文件，运行中复用这些目录结果。

## 进度、网络与恢复

目录检查显示`Directory [当前/总数] 年-月`；`latest`检查也逐月显示。2001–2025需要检查300个月目录，这一步尚未下载风场，耗时随目录响应变化。

数据传输显示已接收MiB、总大小（服务器提供时）、百分比及平均速度，默认最短刷新间隔为0.5秒；网络读取阻塞期间最多等待`--timeout`才报错。裁剪小区域仍需下载全球一天，单日全球文件通常约32MiB，长期下载流量明显大于最终区域文件。

| 参数                               | 用途                                             |
| ---------------------------------- | ------------------------------------------------ |
| `--timeout 90`                   | 单次连接/套接字读取超时秒数，不是整文件总时限    |
| `--retries 3`                    | 请求总尝试次数；仅重试瞬时网络错误及部分HTTP错误 |
| `--proxy direct`                 | 禁用显式代理；VPN/TUN仍可能转发流量              |
| `--proxy http://127.0.0.1:10808` | 为本次运行指定HTTP代理，端口应匹配本机配置       |
| `--progress-interval 0.5`        | 字节进度条刷新间隔秒数，默认 0.5                 |
| `--keep-global`                  | 保留经过校验的全球原件，默认输出成功后删除       |

默认读取环境/系统代理配置。日志不打印代理凭据。出现重试会显示具体月份或日期及HTTP状态、超时、DNS或连接错误类型。缺依赖、磁盘权限、科学校验失败不会反复下载；`Interrupted by user/process signal`表示收到了中断，不等于网络失败。

若需比较代理与直连，可对同一单日命令加`--dry-run`，分别使用默认设置及`--proxy direct`；这只验证目录和HEAD，完整下载仍需单日实测。不要因`dry-run`成功就认定整文件传输一定稳定。

每次只处理一天。源文件先写`raw/*.nc.part`，核对长度、版本、变量、单位、时间、网格与数据可读性后提交；区域输出也先写临时文件、重新打开校验后提交。**不支持字节续传**：未完成的`.part`重跑从头下载，已校验最终文件跳过；已有全球原件可复用。仅缺日均时从已有区域四时次文件生成，无需再下载全球文件。

已有最终文件损坏或请求不匹配时停止，保留文件供检查；更换输出目录或自行检查后移走冲突文件。同一输出目录不要并发运行多个实例。建议至少100MiB临时磁盘、额外最终输出空间及512MiB可用内存。`--keep-global`还需保留全部全球文件的空间。

## 科学含义

官方来源：[RSS产品说明](https://www.remss.com/measurements/ccmp/)、[V3.1实际目录](https://data.remss.com/ccmp/v03.1/)、[NASA PO.DAAC DOI](https://doi.org/10.5067/CCMP-6HW10M-L4V31)。目录覆盖及最新完整年份以执行时实际文件为准，不能假定每一年完整。401/403会停止；认证、许可和引用遵循RSS说明。

源文件为0.25°全球网格，720×1440；纬度中心-89.875..89.875，经度中心0.125..359.875。裁剪按格点中心包含原则，不插值；默认区域实际输出经度105.125–124.875°E（80列）、纬度0.125–24.875°N（100行）。脚本校验真实坐标并更新裁剪后范围。

| 输出           | 变量                   | 单位与含义                                       |
| -------------- | ---------------------- | ------------------------------------------------ |
| 四时次区域文件 | `uwnd`, `vwnd`     | `m s-1`，10m东向/北向风，00/06/12/18 UTC分析场 |
| 四时次区域文件 | `nobs`               | 无量纲卫星观测支持数，0–100；0不代表坏文件      |
| 可选日均       | `uwnd`, `vwnd`     | 四分析时刻等权算术平均，保留原单位               |
| 可选日均       | `nobs_sum`           | 四时次支持数之和，不是去重独立日观测数           |
| 可选日均       | `valid_sample_count` | 两个分量均有效的时次数，0–4                     |

`--daily-mean`额外保存日均，原四时次文件始终保留。日均采用`skipna=False`：某分量任一时次缺测，使该分量日均缺测；缺失、重复、跨UTC日时次直接拒绝，不插值、不用少于四帧平均。日均时间戳为UTC12时，`time_bounds`为当天00时至次日00时。它是四个分析场的离散均值，不能称为独立连续24小时观测平均；原四时次也不是6小时平均。

CCMP融合卫星与调整过的ERA5背景，不能作为与ERA5完全独立的验证资料。RSS不保证陆地风值正确；下游研究仍需海域掩膜。保留上游缺测、科学属性、来源和处理历史，不将所有有限值自动认定为有效海洋观测。
